# My Life｜個人生活管理 PWA

## 內容
- 每週時間表（已加入星期五、六晚間 21:00–23:00 及星期日晚間 17:30–19:15 籃球）
- 功課清單及完成打卡
- 考試日期倒數及溫習進度
- 默書日期、範圍及分數
- 簡單籃球訓練紀錄
- 每週統計
- JSON 匯出／匯入備份
- 本機瀏覽器儲存，不連接帳戶或伺服器

## 安裝到 iPhone 主畫面
PWA 需要透過 HTTPS 網址開啟，不能只靠在 iPhone「檔案」App 直接開啟 HTML 安裝。
1. 將本資料夾內所有檔案部署到支援 HTTPS 的靜態網站空間。
2. 用 iPhone Safari 開啟部署後的網址。
3. 點分享按鈕 →「加入主畫面」→「加入」。
4. 從主畫面開啟 My Life。

## 資料保存與備份
資料存在該網站在 iPhone Safari 的本機儲存空間，不會自動同步到其他裝置。請定期到「統計」→「匯出備份」保存 JSON 檔案。清除 Safari 網站資料、換機或更換網站網址都可能令資料無法直接讀取。

## 注意
這是一個可自行部署的第一版前端 PWA 套件。尚未替你部署到公開 HTTPS 網址，因此目前不能直接從這份 ZIP 一鍵安裝到主畫面。
